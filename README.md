### Featured Projects

#### [ClinicalTriage AI](https://github.com/Thames18/Clinical-Triage)
End-to-end AI clinical triage platform. Patients submit vitals/symptoms through a Next.js frontend; a FastAPI backend runs LLM-driven triage reasoning and generates structured assessments. Async PDF report generation via Celery + Redis, monitored through Flower, protected by JWT auth, deployed to AWS EC2 with GitHub Actions CI/CD.
`Next.js` `FastAPI` `Celery` `Redis` `LLM` `AWS` `Healthcare AI`

#### [Resume on Cloud](https://github.com/Thames18/Resume-On-Cloud)
Serverless portfolio deployment using AWS Lambda, API Gateway, and DynamoDB, fronted by CloudFront with HTTPS and custom domain routing.
`AWS Lambda` `API Gateway` `DynamoDB` `CloudFront` `Serverless`

#### [Stock Market Kafka Pipeline](https://github.com/Thames18/stock-market-kafka-project)
Real-time Kafka pipeline for stock market data ingestion and processing, integrating AWS services for scalable storage and downstream analytics.
`Kafka` `Streaming` `AWS` `Data Engineering`

#### [ML Mortality Prediction](https://github.com/Thames18/Mortality-Prediction)
End-to-end pipeline ingesting, preprocessing, and modeling ICU time-series data from MIMIC-III using RNN and GNN architectures, with a focus on reproducible training/evaluation.
`Machine Learning` `Healthcare` `MIMIC-III`

#### [RNN Mortality Prediction](https://github.com/Thames18/Deep-Learning-RNN-for-Mortality-Prediction)
PyTorch RNN pipeline for ICU mortality prediction using time-series vitals, with a custom DataLoader and reproducible training achieving competitive AUC on MIMIC-III.
`PyTorch` `RNN` `Deep Learning`
